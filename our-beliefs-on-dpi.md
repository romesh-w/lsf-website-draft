We believe the digital public infrastructure that runs a country should be built as open source software: code that anyone can use, study, improve and share. Here is why.

## Independence

In a world of de-globalization and weaponized economics, a country's digital infrastructure should not depend on software that can be withdrawn, restricted or priced out of reach by another power. Open source can be freely developed, deployed and used without those restrictions.

## Security and trust

When the code is open, governments and independent experts can check exactly what it does. Problems can be found and fixed by anyone, rather than hidden inside a product no one outside the vendor can see.

## No lock-in

With open source, a government owns its choices. It can change suppliers, run the software itself, or adapt it to new needs, without being tied to a single company.

## Shared progress

Software built once can be reused by many. A system built for one country can be adapted by another, so every nation benefits from the work of all.
